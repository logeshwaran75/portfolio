# Logeshwaran N: AI/ML Engineer Portfolio

Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS 3 · Motion · Lucide

## Run locally
```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start   # production check
```

## Update content
All content lives in `data/portfolio.ts` (profile, experience, projects, skills, education) and `data/lab.ts` (Interactive Lab walkthroughs).
Search for `TODO` to find placeholders: GitHub profile URL, Uniqus start date and responsibilities, per-project repo/demo links.
Replace the resume at `public/Logeshwaran-N-Resume.pdf` (keep the filename or update `profile.resume`).

## Environment
Optional: copy `.env.example` to `.env.local` and set `NEXT_PUBLIC_SITE_URL`. No secrets are required.
